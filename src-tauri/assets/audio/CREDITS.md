# Tonnachweise

Beide Dateien sind Ausschnitte aus Freesound-Aufnahmen. Sie wurden auf Mono,
48 kHz und 16 Bit gebracht, eingepegelt und für den Einlauf gekürzt.

## `needle_drop.wav`

- Original: „Needle Drop Analogue 2.wav“ von **HenKonen**
- Quelle: https://freesound.org/people/HenKonen/sounds/682161/
- Lizenz: **CC0 1.0** (Public Domain)
- Änderung: Ausschnitt 0,06–0,50 s, auf Peak 0,9 normalisiert, kurze Ein-/Ausblendung.

## `vinyl_static.wav`

- Original: „vinyl_record_needle_static_01.wav“ von **joedeshon**
- Quelle: https://freesound.org/people/joedeshon/sounds/140295/
- Lizenz: **CC BY 4.0** — https://creativecommons.org/licenses/by/4.0/
- Änderung: Ausschnitt 50–58 s, auf RMS 0,06 normalisiert, Spitzen begrenzt,
  Mono/48 kHz. Keine weiteren inhaltlichen Änderungen.

Die Aufnahmen werden zur Laufzeit nur lokal aus der App gelesen; es gibt keine
Netzwerkanfragen.
